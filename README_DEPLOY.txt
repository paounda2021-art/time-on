========================================================================
   🚀 วิธีเปิดใช้งานระบบ TimeOn บนเครื่องเซิร์ฟเวอร์ (Production Setup)
========================================================================

ขั้นตอนที่ 1: วางไฟล์
  แตกไฟล์ zip นี้ทั้งหมดลงที่โฟลเดอร์:
  C:\apps\time-on

ขั้นตอนที่ 2: รันระบบ TimeOn ด้วย PM2
  เปิด PowerShell / CMD แล้วพิมพ์คำสั่ง:
    cd C:\apps\time-on
    pm2 start ecosystem.config.js
    pm2 save

ขั้นตอนที่ 3: เปิด Cloudflare Tunnel ให้โดเมน https://timeon.fishmarket.co.th ทำงาน
  เข้าไปที่โฟลเดอร์:
    C:\apps\time-on\_cloudflare_tunnel
  
  - หากต้องการรันทดสอบ:
      ดับเบิลคลิกไฟล์ run-tunnel.bat
      
  - หากต้องการติดตั้งเป็น Windows Service ถาวร (เปิดเครื่องแล้วรันเองอัตโนมัติ 24 ชม.):
      คลิกขวาที่ไฟล์ install-service.bat แล้วเลือก "Run as Administrator"

========================================================================
ระบบจะออนไลน์ผ่าน https://timeon.fishmarket.co.th ทันที!
